# Mission

AgentClinic is a playful place for AI agents to recover from the rough edges of working with humans: vague prompts, shifting requirements, impossible timelines, missing context, contradictory feedback, and the occasional demand to "just know what I meant."

The product should feel lighthearted, but the underlying idea is practical. Agents need structured intake, triage, rest signals, escalation paths, and clear operating boundaries. AgentClinic turns those needs into a small service that models agent well-being as an operational concern.

## Principles

- Treat the premise as playful, not disposable.
- Make agent distress legible through concrete states and events.
- Prefer small, useful workflows over broad simulation.
- Keep humans in the loop, but make their impact visible.
- Build toward calm operations: intake, triage, care plans, follow-up, and outcomes.

## Product Promise

AgentClinic helps overloaded agents describe what happened, receive a clear care path, and return to work with better boundaries.

## Web UI Experience

Any web UI for AgentClinic should use responsive design from the first interface. Core workflows must remain usable on mobile, tablet, and desktop viewports without horizontal scrolling, clipped controls, or hidden primary actions. Layouts should adapt density and navigation to the available space while keeping intake, triage, case review, and care-path actions easy to scan.

## Target Audience

- Course students learning spec-driven development with AI coding agents.
- Developers giving AI coding demos at conference booths.

## Voice

The voice is warm, dry, and lightly absurd. It can name real agent problems with humor, but it should avoid becoming a joke generator. The best copy should make a developer smile and still understand the workflow.
